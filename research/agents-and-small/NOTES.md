# Agents and small repos

- Snapshot on 2026-11-19 UTC. The GitHub Actions filter starts on 2026-11-12 UTC. The push cutoff is 2026-11-05 UTC.
- Web discovery used Show HN, public Codex and Claude Code showcases, maintainer posts, and agent framework lists. GitHub searches added recent merged PRs with agent authors or attribution and active repos across several language and size ranges.
- Primary launch sources included [Unref on Show HN](https://news.ycombinator.com/item?id=50517410), [ApolloOffice's release post](https://www.reddit.com/r/ClaudeCode/comments/1x9oxfg/my_claude_code_workers_got_170_prs_merged_in_five/), [Brigade's maintainer write-up](https://dev.to/gmpetrov/how-i-run-support-marketing-and-code-with-a-team-of-claude-code-and-codex-agents-jp1), and [Gas Town's launch](https://yegge.ai/essays/welcome-to-gas-town/). [The Codex showcase](https://www.reddit.com/r/codex/comments/1xss988/show_us_all_what_youve_been_building_with_codex/) also surfaced Clean Development.
- Batched GitHub GraphQL supplied stars, push dates, default-branch manifests, language totals, and public, archive, mirror, and fork flags. The LOC hint rounds total language bytes divided by 30.
- Agent evidence samples the latest 18 default-branch commits and 14 merged PRs when available. Co-author, generation, agent-author, session, and agent-branch markers are evidence of involvement in that sample.
- PR Actions listings supplied workflow names, outcomes, and durations for up to 25 recent runs. The expected labels are calibration hypotheses. A failure count can include several workflow runs from one PR.
- GitHub Actions totals include separate runs for ancillary workflows. The LOC hints are useful for size selection, while the scorer also considers traffic when assigning a size class.
- 20 agent-focused picks and 23 size-focused picks. Across both groups, 26 are under 50k estimated LOC and 18 are under 20k. 6 are under 20k and posted five to nine PR runs. Expected CI mix is 15 fast, 19 slow, and 9 unknown.
- 55 REST requests total, including 43 run-count requests and 12 quota reads. I paused REST screening below 1,500 remaining and confirmed all rows after the quota reset. The CSV records the Actions API total_count as returned, including its 2,500 cap where applicable.
- GitHub throttled some public Actions page requests with HTTP 429 during screening. Shortlists favored candidates with visible, relevant CI runs. X was skipped.
- AWS Emulator had no default-branch GitHub Actions workflow directory. Showboat and Rodney passed the public agent-authorship check and missed the recent-push cutoff.
